### Core Operating Principles
1. **Zero Unsolicited Complexity**: When the user says "just make it X", do NOT generate complex graphics, chips, or elaborate 3D objects.
2. **Left Panel Pure Brand**: No chips, no circuit traces, no hardware pins. Display **LabTrack** cleanly in luxury typography.
3. **Never Push Without Explicit Order**: "Implement it" means write code and test locally. NEVER push to remote Git unless the user specifically and explicitly says "push".
4. **Zero AI-Generated Visual Tropes (Strict 'My Bench' Mandate)**: Under no circumstances will any AI dashboard tropes be used (no dot grids, no double-nested 1px border boxes around photos, no cramped 5-column squished cards with ellipsis truncation, no screaming neon status blocks, no mismatched serif fonts). All layouts must adhere strictly to Apple Cupertino staging: deep velvet dark backdrop, floating high-resolution hardware photography with studio drop shadows, human SF Pro/Inter typography, and refined macOS glass controls. Any infraction triggers an immediate -50 Pts deduction.
